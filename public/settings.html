Admin API key

One of the values in ADMIN_API_KEYS. Stored only in this browser (localStorage), sent as X-Api-Key. On the Home Assistant add-on, if you left admin_api_keys blank in Configuration, one was auto-generated for you on first boot - check this add-on's Log tab for a one-time notice with the value.

Users

The admin key above is only for this Settings page - it does not work in + New Reminder. Each person needs their own user, created here, with their own personal API key. Optionally link a user to a Home Assistant account (below) so they don't need an API key at all when opening the app from the HA sidebar.

Storage backend(s)

Pick any combination. With more than one enabled, writes go to all of them and the first one you check is treated as primary for reads.
